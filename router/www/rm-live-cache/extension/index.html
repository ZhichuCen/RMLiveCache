安装官方页面缓存扩展

扩展只把官方播放器固定到局域网720P主视角，不读取登录信息、奖励数据或聊天内容。

下载扩展 ZIP
  1. 先解压 ZIP；不能直接把 ZIP 交给“加载已解压的扩展程序”。
  2. Chrome 打开 chrome://extensions，Edge 打开 edge://extensions。
  3. 开启“开发者模式”，选择“加载已解压的扩展程序”，选中里面直接含有 manifest.json 的文件夹。
  4. 打开官方直播页，在地址栏左侧打开“网站设置”，将“不安全内容”设为“允许”，再刷新页面。该权限只用于读取场地内的 HTTP 视频缓存。
  5. 若浏览器另行询问本地网络权限，请选择允许。
  6. 保持官方直播标签页可见并确保播放器正在播放，奖励计时才会继续。
